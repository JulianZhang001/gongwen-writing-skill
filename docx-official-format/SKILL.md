# Word 公文印制格式排版

把已有 Word 文档排成规范的公文印制格式。**只排版式，不改内容。**

## 工作流程

当用户要求把 `.doc` 或 `.docx` 排成公文格式时：

1. **保留原始文档不动** —— 所有输出写到新文件。
2. 需要详细格式规则时读 [`references/official-format.md`](./references/official-format.md)。
   默认标准是本地《文件印制格式基本要求》；GB/T 15834 标点检查只作为辅助校验。
3. 运行 `scripts/format_docx.py`，输入原文件路径、输出路径以 `_公文格式.docx` 结尾。
4. **保持原文含义与顺序**。标点可以做安全归一化；不确定的标点或措辞问题，
   用 Word 批注标出来，不要擅自改。
5. 有条件时渲染输出并目视检查。返回生成的 `.docx` 路径，并简要列出应用了哪些格式。

## 命令

```bash
python3 scripts/format_docx.py input.docx output_公文格式.docx
```

也支持旧的 `.doc` 输入 —— 脚本会先在临时目录转成 `.docx` 再排版：

```bash
python3 scripts/format_docx.py input.doc output_公文格式.docx
```

可选自定义字体：

```bash
python3 scripts/format_docx.py input.docx output.docx \
  --title-font 方正小标宋_GBK --body-font 方正仿宋_GBK \
  --heading-font 方正黑体_GBK --secondary-heading-font 方正楷体_GBK
```

## 默认格式

- **页面**：A4。页边距 上 `35mm`、下 `29mm`、左右各 `25.5mm`；页眉 `15mm`、页脚 `22mm`。
- **段落**：固定行距 `30pt`。若一级标题被挤到页面最后一行成为孤行，
  可微调该页行距或字距以求视觉平衡。
- **标题**：首个标题块，居中，`方正小标宋_GBK`，二号 `22pt`，加粗；
  支持主送机关段之前的多行标题。
- **副题**：可选，紧跟标题之后，居中，`方正楷体_GBK`，三号 `16pt`。
- **主送机关**：标题/副题之后，第一个以 `：` 结尾的非空段落，左对齐，
  `方正仿宋_GBK`，三号 `16pt`。
- **正文**：`方正仿宋_GBK`，三号 `16pt`，固定行距 `30pt`，首行缩进 `2` 字符。
- **一级标题 `一、`**：`方正黑体_GBK`，三号 `16pt`，首行缩进 `2` 字符。
- **二级标题 `（一）`**：`方正楷体_GBK`，三号 `16pt`，首行缩进 `2` 字符。
- **三级标题 `1.`**：`方正仿宋_GBK`，三号 `16pt`，**加粗**，首行缩进 `2` 字符。
- **四级标题 `（1）`**：`方正仿宋_GBK`，三号 `16pt`，首行缩进 `2` 字符。
- **附件说明**：用正文字体，首行缩进 `2` 字符，位于正文之后、发文机关署名之前，
  上方空一行。多个附件用阿拉伯数字编号。附件名称末尾不加标点。
- **发文机关与日期**：仅当最后一个日期段落紧接在机关名称段落之后时才成对处理；
  两者右对齐且右缩进同为 `4` 字符，使右边缘对齐。
  **不要把较长的机关名称做居中** —— 机关名称比日期宽时，居中会把它推出右边距。
  若未识别出这一对，尾部段落按普通正文处理。
- **联系人行**：格式为 `（联系人：……；联系电话：……）`，用正文字体。
- **页码**：宋体 四号，外侧对齐，首页无页码，数字两侧加横线，形如 `— 2 —`。
- **中英混排**：拉丁字母、阿拉伯数字、`%`、小数点、千分位用 **Times New Roman**
  （写 `w:ascii`/`w:hAnsi`/`w:cs` 三个槽位）；汉字与全角标点用中文字体（`w:eastAsia`）。
  每个 run 必须声明 `w:hint` —— 中文 run 用 `eastAsia`，纯西文 run 用 `default`；
  **全角引号要独占一个 run**，否则会渲染成直引号。
- **标点**：归一化常见 GB/T 15834 问题，如中文全角标点、`附件：`、
  标题末尾标点、年份六角括号 `〔〕`、省略号 `……`、阿拉伯数字日期格式；
  不确定的标点问题加 Word 批注。

## 注意事项

- **不要**擅自加印章、红头、发文字号或版记，除非用户明确要求。
- 源文档有表格时，表格文字居中并使用正文字体。
- 所需字体本机未安装时，**仍要把字体名写进 Word 文件** ——
  这样在装该字体的机器上打开就能正确渲染。
- 署名块被挤到第二页时，调整**行距**（如 `30pt` → `29.5pt`）加上署名的
  `space_before`。改字距（`w:spacing`）不会改变断行位置，没有用。
- **用渲染出的 PDF 实测版式，不要只信公式**：对每个块计算
  `(版心右边界 − block.x1) / 字号pt`，确认发文机关与日期两个块算出同一个值。
