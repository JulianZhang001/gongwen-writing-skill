# 示例对照

这里放常见公文场景的**前后对照**示例 —— 看原始草稿怎么变成可送审的正式稿。

## 包含哪些示例

| 文件 | 场景 | 主要看点 |
| --- | --- | --- |
| [`新闻稿示例.md`](./新闻稿示例.md) | 校园/机关新闻稿 | 去口语化、提炼导语、规范称谓 |
| [`讲话稿示例.md`](./讲话稿示例.md) | 会议讲话稿 | 层次重排、压缩空话、强化落点 |
| [`通知示例.md`](./通知示例.md) | 事务性通知 | 事项说清、责任到人、时限明确 |
| [`校园新闻稿完整示例.md`](./校园新闻稿完整示例.md) | 完整长文新闻稿 | 从素材到成稿的完整改写过程 |

## 每个文件的结构

统一按三段呈现，方便你对照：

1. **原始草稿** —— 待处理的素材或初稿
2. **润色后成稿** —— 可直接使用的正式版本
3. **修改说明** —— 改了什么、为什么这么改

## 怎么用

- 想了解效果 → 直接读对照
- 想自己动手 → 把草稿喂给 `official-document-writing-polisher`，再和示例比对
- 想配套排版 → 润色完成后交给 `docx-official-format` 排成公文版式
